# Major Run

Major Run is a Counter-Strike inspired tournament simulation game where you build your own team and try to win the Major.

The game combines player drafting, team composition, role management and tournament simulation into a complete campaign.

## Features

* Player draft system
* Team composition and role conflicts
* Star Player system
* Random tournament teams
* Swiss Stage
* Playoff progression
* Random competitive maps
* Match and score simulation
* Tournament campaign summary
